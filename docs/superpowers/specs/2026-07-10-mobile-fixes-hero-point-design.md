# 모바일 호환성 수정 + 메인화면 포인트 디자인

날짜: 2026-07-10 · 상태: 사용자 승인 완료

## 배경

- 모바일(390px)에서 "깨진다"는 사용자 피드백. Playwright 진단 결과 가로 오버플로/JS 에러는 없고, 아래 4건이 원인.
- 메인화면(index.html)은 현재 깔끔한 디자인을 유지하되 시선을 끄는 "포인트"가 필요.

## A. 모바일 수정 (4건)

1. **스크롤 스냅 해제 (모바일 전용)** — `scroll-snap-type: y mandatory`가 모바일에서 뷰포트보다 1.5~3.3배 긴 섹션(career 1266px, projects 2777px)과 충돌. `@media (max-width: 768px)`에서 `scroll-snap-type: none`. 데스크톱 유지.
2. **⚡ 성능 배지 모바일 숨김** — fixed 배지가 통계 카드·커리어 카드 텍스트를 가림. 모바일에서 `display: none` (dot-nav·커스텀 커서와 동일한 기존 패턴).
3. **fear-greed 탭바 가로 스크롤** — 좁은 화면에서 탭 라벨이 낱말 중간 줄바꿈·잘림. `.tabs`에 `overflow-x: auto` + `white-space: nowrap`, 탭 `flex-shrink: 0`.
4. **word-break: keep-all** — index/commerce 등 한국어 제목·본문이 낱글자로 꺾임. 주요 헤딩·본문에 적용.

## B. 메인화면 포인트 (4건)

1. **히어로 시그니처** — 헤드라인 "안정성을 설계하는 개발자입니다"의 핵심 단어("안정성")에 그린 하이라이트 스윕 애니메이션(진입 시 1회, 형광펜 효과). 서브 문구 타이핑 로테이션(예: 공공 시스템 운영 6년 → 구조를 개선하는 개발 → 기획부터 배포까지). prefers-reduced-motion 시 정적 표시.
2. **라이브 데이터 티커** — 히어로 하단에 공포탐욕지수·KOSPI·USD/KRW 미니 스트립. 기존 `/api/proxy` 재사용. 로드 실패(로컬 등) 시 스트립 자체를 숨겨 깨짐 없음. "살아있는 사이트" 인상 + fear-greed 앱으로의 자연스러운 유도.
3. **스크롤 내러티브** — 상단 3px 그린 스크롤 프로그레스 바 + 각 섹션 라벨에 01–05 넘버링. 기존 dot-nav와 공존.
4. **프로젝트 카드 강화** — 호버 시 썸네일 살짝 줌(scale 1.04) + 상단 컬러 스트립 그라데이션 스윕. 기존 3D tilt 유지.

## 제약

- 단일 HTML 파일 원칙 유지, 외부 라이브러리 추가 없음.
- 다크/라이트 테마 모두 대응.
- reduced-motion 존중 (Phase 1에서 추가한 미디어쿼리와 일관).
